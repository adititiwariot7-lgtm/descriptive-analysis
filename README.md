# Spotify-Style Streaming Descriptive Analytics 🎵📊

A data analytics project that analyzes Spotify-style streaming data to identify trends in **streams, revenue, regions, content types, subscription segments, playback completion, and cache risk**.

### Key Highlights

* 5.14M total streams
* $5.68M revenue
* 97.5% playback completion
* 60 markets and 10 content types
* Future scope: **predictive analytics, demand forecasting, fraud detection, and cache optimization**
